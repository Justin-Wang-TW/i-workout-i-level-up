# iPhone 捷徑：每天 4 次自動同步步數與運動

捷徑每天 12:00、18:00、22:00、23:50 讀取「健康」App 當天的步數、步行＋跑步距離、運動時間，
送到 `sync-health` 函式。打開遊戲時會自動抓回來，步數與運動功課的修為不再減半。

> 遊戲裡「設定 › 連結 iPhone 健康」有同樣的教學，並可一鍵複製「同步網址」與「同步金鑰」。

## 1. 取得同步網址與金鑰

打開遊戲 › 設定 › 連結 iPhone 健康 › **產生同步金鑰**。
金鑰只顯示一次；遺失就重新產生（舊的會失效，捷徑也要換新）。

## 2. 製作捷徑（約 5 分鐘）

動作名稱依 iOS 版本可能略有不同，括號內為英文介面名稱。

1. 打開「捷徑」App，點右上「＋」，捷徑名稱取為 **我運動我升級同步**（遊戲的「執行捷徑」按鈕靠這個名字找到它）。
2. 加入 **尋找健康樣本**（Find Health Samples）：類型「步數」，條件「開始日期」「是今天」。
3. 加入 **計算統計資料**（Calculate Statistics）：「總和」。把結果變數重新命名為「步數」。
4. 重複 2–3：類型「步行 + 跑步距離」，單位「公里」，結果命名「距離」。
5. 重複 2–3：類型「運動時間」（Apple Exercise Time），結果命名「運動分鐘」。
6. 加入 **取得 URL 的內容**（Get Contents of URL），點「顯示更多」：
   - URL：同步網址
   - 方法：POST
   - 標頭：`x-sync-token` ＝ 同步金鑰
   - 要求本文：JSON，新增「數字」欄位
     `steps` ＝ 步數、`walkRunKm` ＝ 距離、`exerciseMin` ＝ 運動分鐘
7. 加入 **取得字典值**（Get Dictionary Value）：鍵 `message`；再加入 **顯示通知**，內容為這個值。
8. 按 ▶ 執行一次。第一次會詢問是否允許讀取健康資料，選「允許」。看到「11/24 已同步・8,423 步…」就成功了。

## 3. 每天自動執行 4 次

在「自動化」分頁建立 4 個個人自動化，每個都設定：＋ › **特定時間** › 時間 › **每天** › **立即執行** › 選「我運動我升級同步」。

| 時間 | 用途 |
| --- | --- |
| 12:00 | 上午的步數，午餐後就能領部分功課 |
| 18:00 | 下班前後的進度 |
| 22:00 | 晚間運動後更新 |
| 23:50 | 當天最終數字（23:59 前送出才算當天） |

同一天重複送出時，雲端以最新數字覆寫；遊戲的功課只能領一次，不會重複計算修為。

手機關機或沒電而漏掉時：打開遊戲 › 設定 › 執行捷徑，或明天手動執行（7 天內的資料都能補送）。

## 傳送格式

```http
POST https://<專案代碼>.supabase.co/functions/v1/sync-health
x-sync-token: iwlu_xxxxxxxx
Content-Type: application/json

{
  "date": "2026-11-24",          // 選填，省略則為今天（台北時間）
  "steps": 8423,
  "walkRunKm": 6.1,
  "exerciseMin": 42,
  "workouts": [                  // 選填，進階版：逐筆體能訓練
    { "type": "Running", "start": "2026-11-24T19:02:00+08:00", "durationMin": 34, "distanceKm": 5.2, "manual": false }
  ]
}
```

回應：`{ "ok": true, "message": "11/24 已同步・8,423 步・運動 42 分・6.1 公里。已達揮汗門檻，打開遊戲領取修為！" }`

## 判定方式

| 項目 | 簡易版（只送加總） | 進階版（送 workouts） |
| --- | --- | --- |
| 步數型（8,000 步） | 當日步數 | 同左 |
| 時間型（30 分鐘） | 當日運動時間加總 | 單次體能訓練時長 |
| 距離型（5 公里） | 當日步行＋跑步距離加總 | 單次步行／跑步距離 |

簡易版較寬鬆，但設定最簡單；
每次同步送的都是「今天到目前為止」的加總，所以早上達標的功課，中午那次同步後就能領取。
想更貼近揮汗有禮「單次」規則，可改送 workouts。
在「健康」App 手動輸入的體能訓練若標記 `manual: true`，修為減半。
